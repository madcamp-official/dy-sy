# 03 VR Player
기존 VRPawn을 조사하고 MaxHealth 100, CurrentHealth 100, 피해, 사망, 입력 비활성화, 재시작을 추가한다. 기존 이동과 Snap Turn을 보존한다.

## 공통 실행 규칙
- AGENTS.md, CODEX.md, AI_MEMORY.md를 먼저 읽는다.
- Use the connected unreal_mcp server.로 시작한다.
- 변경 전 계획을 보고한다.
- 실제 에셋 경로를 확인한다.
- 변경 후 Compile, Error Check, Reference Check를 수행한다.
- /Game/Maps/L_Test에서 검증한다.
- AI_MEMORY.md를 갱신한다.
